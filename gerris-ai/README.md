# gerris.ai

Gerris: AI search visibility, AEO, GEO, and SEO. The AI services practice of
Gerris Corp, led by Chris Abraham, Arlington, Virginia.

Plain static HTML on GitHub Pages. No build step, no framework, one
stylesheet. Pages: home, services, about, 404. Machine layer: llms.txt,
llms-full.txt, sitemap.xml, robots.txt, JSON-LD schema on every page.

Alpha 1 launched November 6, 2026.
