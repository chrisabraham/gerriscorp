Work with me

A sensible next step is a paid diagnostic with a clear question and a clear deliverable. Everything else builds from there.

Ways to engage

  • Diagnostic. Evidence, priorities, and a recommended next step, for a defined site and a defined set of questions.
  • Implementation sprint. Agreed fixes or deliverables, verified on the live site against written acceptance criteria.
  • Migration review. Pre-launch or post-launch checks and developer coordination for a named site.
  • Ongoing support. An agreed monthly capacity for search, content, and website work.

Payment

  • Diagnostics are prepaid.
  • Projects start with a deposit.
  • Retainers are billed at the start of each month.
  • Invoices are due on receipt, and work resumes once they're paid.

Where the work happens

Every project runs in Basecamp or by email, threaded and on the record, so you always know the status and nothing gets lost.

What helps

  • Access to Search Console, analytics, and the CMS or repository I'll work in.
  • An introduction to your developer, host, or marketing team.
  • Prompt answers. A project that goes quiet closes, and restarts with a fresh scope when you're ready.
