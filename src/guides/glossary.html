Glossary of SEO, AI search, and technical website terms

Plain definitions of the terms that come up in my work, written so each one makes sense on its own. The index lists every page where a term comes up.

301 redirect
A permanent redirect from one URL to another. Search engines transfer the old URL's ranking signals to the new one. The 308 status code is also permanent; 302 and 307 are temporary.
Acceptance criteria
The plain statements a finished change has to satisfy before anyone calls it done, written before the work starts. They turn a request into something a developer can build and a reviewer can check.
AEO (answer engine optimization)
Shaping content so it directly answers the questions people ask, in a form that search features and AI assistants can quote.
AGENTS.md
A Markdown file at the root of a repository holding the build steps, checks, and house rules that AI coding agents read before they work. Codex, Cursor, Gemini CLI, and many other agents look for it. See Several AI agents, one repository.
AI Mode
Google Search's conversational, AI-generated search experience, which answers questions with a written response and links, built on Google's search index.
AI Overviews
The AI-generated summaries that appear at the top of many Google search results, with links to the pages they draw on.
AI washing
Claiming artificial intelligence a product doesn't really use, or overstating what its AI does. The SEC brought its first AI washing cases in March 2024; see how to vet an AI vendor's pitch.
Alt text
A text description of an image in the HTML alt attribute, read aloud by screen readers and used by search engines to understand the image.
Amara's law
Roy Amara's observation that people overestimate a technology's effect in the short run and underestimate it in the long run. It's the first test in hype or real shift.
Backlink
A link on someone else's website that points to a page on yours. Links are one of the signals search engines use to judge which pages deserve to rank, so a migration or redesign has to carry them to the new addresses.
BIMI
Brand Indicators for Message Identification: a DNS record that lets supporting inboxes show a brand's logo beside authenticated email. It requires DMARC enforcement.
Bing Webmaster Tools
Microsoft's free service for monitoring a site in Bing, whose index also feeds Microsoft Copilot and other AI assistants.
Canonical tag
A link element that tells search engines which URL is the preferred version of a page when several URLs show the same or similar content. Google treats it as a strong hint.
CDN (content delivery network)
A network of servers around the world that stores copies of a site's files close to visitors, making pages faster and absorbing traffic spikes and attacks. Cloudflare is the best-known example.
Citation gap
A page AI assistants cite when answering your buyers' questions that names your competitors and leaves you out. Finding them is the job of a citation gap analysis.
Cloudflare
A network that sits in front of many websites, providing DNS, caching, a content delivery network, and protection from attacks. Its settings can help or hurt search and AI crawlers; see Cloudflare settings that help or hurt SEO and AI crawlers.
CLS (Cumulative Layout Shift)
A Core Web Vital measuring how much visible content moves unexpectedly while a page loads. Good is 0.1 or less.
Confabulation
NIST's term for a generative AI system stating false information with confidence. The reason AI-assisted work needs a human check. See AI use policy.
Consent Mode
Google's system for adjusting what GA4 and Google's other tags may store and measure, based on the consent each visitor gave. See Google Consent Mode v2 for GA4.
Content brief
A one-page instruction that settles a page's question, answer, evidence, and limits before anyone writes. See writing a content brief.
Core update
A broad recalibration of Google's ranking systems, announced a few times a year and logged on the Search Status Dashboard. Losses after one reflect being outranked, and Google says recovery can take months.
Core Web Vitals
Google's three page experience metrics: Largest Contentful Paint, Interaction to Next Paint, and Cumulative Layout Shift, measured from real Chrome users.
Crawl budget
How many URLs a search engine is willing and able to crawl on a site in a given period. It matters mostly for large sites and sites with many low-value URLs.
Crawled, currently not indexed
A Google Search Console status meaning Google fetched a page and chose not to index it. See the full guide.
Crawler Hints
A free Cloudflare feature that watches content change as it passes through Cloudflare's cache and notifies IndexNow engines such as Bing. Google doesn't take part.
Data broker
A company that collects personal information from public records and other sources and sells it or publishes it in people-search listings. Getting a name out takes an opt-out at each broker; see how to remove your personal information from data brokers and search.
Discovered, currently not indexed
A Search Console status meaning Google knows a URL exists and hasn't crawled it yet, usually a sign of crawl priority problems.
DKIM
DomainKeys Identified Mail: a cryptographic signature on outgoing email, verified against a public key published in DNS.
DMARC
A DNS policy telling receiving mail servers what to do with mail that fails SPF and DKIM alignment, and where to send reports. Policies are none, quarantine, and reject.
DNSSEC
Signatures added to DNS records so resolvers can reject forged answers. Turn it off or move the keys before changing DNS hosts. See domain security.
E-E-A-T
Experience, expertise, authoritativeness, and trustworthiness: the qualities Google's quality rater guidelines ask raters to assess, and a useful description of what makes content credible.
Email blocklist
A list of IP addresses and domains that spam filters consult to reject or junk mail, also called a DNSBL. Getting off one starts with fixing the cause; see blocklist recovery.
Endorsement Guides
The FTC's guidance on testimonials and influencer posts, 16 CFR Part 255, last revised in 2023. They hold the advertiser answerable for what paid endorsers say. Covered in the creator vetting guide.
Entity
A distinct thing that search engines and AI systems keep as its own record: a person, a business, a place, or a product, with facts and profiles attached to it. Facts that agree across a site, its listings, and its profiles are how machines stay sure which entity a page describes.
European Accessibility Act
EU Directive 2019/882, applied since June 28, 2025, requiring accessible e-commerce, banking, e-books, and other consumer services, including from sellers outside the EU. See the EAA guide.
Faceted navigation
The filter links on a catalog or listing site that combine choices such as size, color, and price into new URLs. Every combination can become a page, so the crawl needs rules; see faceted navigation SEO.
Force push
A Git push that overwrites the shared branch even when it holds commits the pusher never saw, which deletes other people's work. --force-with-lease refuses if the branch moved. See Several AI agents, one repository.
GA4 (Google Analytics 4)
Google's current analytics system, which records visits, searches, and conversions as events. It replaced Universal Analytics, and most measurement questions on a business site now start with its reports.
GEO (generative engine optimization)
Making a business and its content easy for AI systems to find, understand, and cite in generated answers.
Git
The version control system almost every software team uses. It records each change to a set of files, who made it, and why, so any version can be restored.
GitHub Pages
GitHub's hosting for static websites, which serves a site straight from a repository at no charge. This site runs on it; see a real business website for the price of a domain name.
Google Business Profile
The free Google listing that controls how a business appears in local search results and on Google Maps: address, hours, photos, reviews, and services. See Google Business Profile hard cases.
Google Search Console
Google's free service for monitoring how a site appears in Google Search: indexing, queries, clicks, Core Web Vitals, and errors.
hreflang
An annotation that tells search engines which language or regional version of a page to show to which users.
HSTS (HTTP Strict Transport Security)
A response header that commits browsers to HTTPS for a site for a chosen length of time. Add preload only once every subdomain serves HTTPS, because preload is slow to reverse.
Hype cycle
Gartner's curve for a new technology's reputation: a trigger, a peak of inflated expectations, a trough of disillusionment, a slope of enlightenment, and a plateau of productivity.
Indexing
The step where a search engine stores a crawled page in its index, the database its answers are drawn from. A page can be crawled and still left out, and a page outside the index cannot appear in results.
IndexNow
An open protocol that lets a site notify Bing, Yandex, and other participating search engines immediately when pages are added, changed, or removed.
INP (Interaction to Next Paint)
A Core Web Vital measuring how quickly a page responds to taps, clicks, and key presses. Good is 200 milliseconds or less. It replaced First Input Delay in March 2024.
Internal linking
Links between pages of the same website. They carry readers to the next useful page and show crawlers which pages matter and how the topics connect. See internal linking strategy and implementation.
JSON-LD
A format for adding structured data to a page in a script block, recommended by Google for schema.org markup.
LCP (Largest Contentful Paint)
A Core Web Vital measuring how long the largest visible element, usually a hero image or headline, takes to appear. Good is 2.5 seconds or less.
llms.txt
A proposed convention, introduced in 2024, for a plain Markdown file at a site's root that summarizes the site and links to its key pages for language models. Adoption by AI companies is still emerging. This site publishes one.
Material connection
Any tie between an endorser and a brand that the audience wouldn't expect, such as payment, free product, family, or employment. The FTC expects it disclosed in each post. See vetting a creator before a sponsorship.
Meta description
A short summary of a page in its HTML head, often shown under the title in search results. Usually 140 to 160 characters.
Migration
Moving a website to a new domain, platform, or structure. The search work is the inventory of old URLs, the redirect map, and the checks in the weeks after launch; see the website migration SEO checklist.
noindex
A meta robots instruction, or an X-Robots-Tag response header, telling search engines to keep a page out of the index. The page can still be crawled, and the links on it can still be followed.
OAI-SearchBot
OpenAI's crawler for ChatGPT search. It's controlled separately from GPTBot, the training crawler, so a site can appear in ChatGPT answers while declining to be used for training.
Orange cloud (proxied)
A Cloudflare DNS record whose traffic runs through Cloudflare's network, gaining caching, compression, and attack protection. Gray means Cloudflare answers DNS and steps aside.
Programmatic SEO
Building many pages from one template and a data set, such as a page for every location or product. The pages earn their place when each one answers its own query in full; see programmatic SEO, where it works and why Google ignores it.
Pull request
A proposed set of changes to a repository, presented for review and comment before it's merged. Requiring one for every change gives an owner a complete history; see hiring developers.
README
The introductory file at the top of a code repository. On a public GitHub repository it's a public page that AI assistants with web search read, so it should describe the live site; see your README is a source AI reads.
Registrar lock
Status codes such as clientTransferProhibited that tell the registry to refuse transfers, deletions, or updates until the account holder lifts them. Registry Lock is the stricter, registry-level version.
Repository
The folder of code and content Git tracks, along with its full history. Owning the repository, in an account the business controls, is owning the website.
Restore drill
Rebuilding a website from its backup on a separate server, timed and written down, to prove the backup is complete before an emergency. See restore drills.
robots.txt
A file at a site's root that tells crawlers which paths they may fetch. It controls crawling, not indexing; a blocked page can still appear in results if other sites link to it.
Scaled content abuse
The spam policy covering mass-produced pages made mainly to rank, by any method, human or machine. Google's 2026 spam updates focused on it.
Schema.org
The shared vocabulary search engines use for structured data, describing organizations, people, products, services, articles, events, and much more.
SEO (search engine optimization)
The work of making a website easy for search engines to crawl, understand, and rank for the questions buyers ask. It covers the technical health of the site, content that answers in full, and the links and listings that confirm the business behind it.
Server-side rendering
Generating a page's full HTML on the server before sending it, so browsers and crawlers receive the content without running JavaScript. Static generation does the same at build time.
Site reputation abuse
Hosting third-party pages on an established site so they ride its reputation in search. Google introduced the policy in 2024 and updated it in August 2026.
Soft 404
A page that tells visitors it doesn't exist or has nothing to show, while returning a 200 success status. Google treats it as an error.
Spam update
An upgrade to the systems that detect violations of Google's spam policies. Unlike a core update, it targets specific behavior, and the sites it catches tend to fall fast.
Speculation rules
A JSON block in a script tag that tells Chrome and Edge which links to prefetch or prerender before the reader clicks, so the next page opens at once. See speculation rules.
SPF
Sender Policy Framework: a DNS record listing the servers allowed to send email for a domain. It allows at most ten DNS lookups.
Static site
A website served as finished HTML files, with no database or application building each page as it is requested. Static sites load fast, cost little to host, and leave little to break.
Structured data
Machine-readable information about a page, usually schema.org in JSON-LD, describing what the page is about and how it relates to people, organizations, and other pages.
Title tag
The HTML title of a page, shown in browser tabs and usually as the headline of a search result. Usually 50 to 60 characters.
TTFB (time to first byte)
How long a browser waits for the first byte of a server's response. Slow TTFB delays everything else, and caching and CDNs reduce it.
WCAG (Web Content Accessibility Guidelines)
The W3C accessibility standard, now at version 2.2. Level AA is the benchmark US courts and EU standards most often point to. See accessibility remediation.
Worktree
An extra working folder attached to the same Git repository, on its own branch, so two jobs can change files without touching each other's copy. See Several AI agents, one repository.
XML sitemap
A file listing the URLs a site wants search engines to crawl, with optional last-modified dates.
